# Earthquake Weather Alert for AstrBot

AstrBot 插件：地震预警 + 气象灾害预警 + 实时天气查询，支持私聊推送。

## 功能

- **地震预警**：轮询成都高新减灾研究所接口，自动计算震中距、预估烈度、P/S 波到达时间
- **气象灾害预警**：轮询和风天气，支持蓝/黄/橙/红四级，自动去重
- **实时天气**：群内发送 `天气` 指令查询配置地址的实况
- **每日天气推送**：定时推送当日天气概况
- **全部配置可视化**：地址、QQ、Key、阈值均通过 WebUI 设置，无需改代码

## 数据源

| 功能 | 来源 | 费用 |
|------|------|------|
| 地震预警 | 成都高新减灾研究所（大陆地震预警网） | 完全免费，无 Key |
| 气象预警 / 天气 | 和风天气 devapi | 个人开发者 5 万/月免费额度 |

## 安装

1. 将本插件文件夹复制到 AstrBot 的 `data/plugins/` 目录下：
   ```
   data/plugins/earthquake_weather_alert/
   ├── _conf_schema.json
   ├── __init__.py
   ├── main.py
   └── metadata.yaml
   ```

2. 重启 AstrBot 或 WebUI 中执行 **重载插件**。

3. 进入 AstrBot WebUI → **插件** → 找到 **地震+气象预警推送** → 点击 **配置**。

4. 填写以下必填项：
   - **监测地址**：用于 GeoAPI 解析和天气查询，例如 `成都市双流区`
   - **推送目标 QQ 号**：预警消息将私聊推送给该 QQ，例如 `1234567890`
   - **和风天气 API Host**：前往和风天气控制台 → 设置 → 复制你的 API Host
   - **和风天气 Web API Key**：前往 [dev.qweather.com](https://dev.qweather.com) 注册个人开发者，新建 Web API 项目获取 Key

5. 保存配置，再次重载插件。

> 配置变更后必须重载插件才能生效。

## 环境变量（可选）

Docker 部署时可不编辑配置文件，直接通过环境变量注入和风 Key：

```bash
export QWEATHER_KEY=你的和风Key
```

环境变量优先级高于 WebUI 配置。

## 指令

在 AstrBot 接入的任意群聊或私聊中发送：

| 指令 | 说明 |
|------|------|
| `天气` | 查询配置地址的实时天气（温度、体感、风向、湿度、能见度） |
| `地震测试` | 发送一条模拟地震预警到配置的私聊目标，用于验证推送链路 |
| `预警测试` | 发送一条模拟气象预警到配置的私聊目标，用于验证推送链路 |
| `预警状态` | 查看插件运行状态、位置解析结果、已推送数量、轮询时间、阈值配置 |

## 配置项说明

| 配置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 监测地址 | string | 空 | 用于 GeoAPI 解析经纬度和天气查询 |
| 推送目标 QQ 号 | string | 空 | 私聊推送目标 |
| 和风天气 API Host | string | 空 | 和风天气控制台中的专属 API Host |
| 和风天气 Web API Key | string | 空 | 和风天气个人开发者 Key |
| 最小震级阈值 | float | 3.0 | 低于此震级的地震不推送 |
| 最小气象预警级别 | string | 蓝色 | 可选：蓝色 / 黄色 / 橙色 / 红色 |
| 地震轮询间隔（秒） | int | 30 | 建议不低于 30 秒 |
| 气象预警轮询间隔（秒） | int | 300 | 建议不低于 300 秒（5 分钟） |
| 每日天气推送时间 | string | 08:00 | HH:MM 格式，留空则关闭 |

## 精确度说明

| 维度 | 精确度 | 说明 |
|------|--------|------|
| 天气查询 | 街道级 | 通过 GeoAPI 解析地址 → 格点天气数据 |
| 气象预警 | 区县级 | 政府预警最小发布单位为区县，无法精确到街道 |
| 地震预警 | 震中坐标 ±100m | 含震中距、预估烈度、P/S 波到达时间计算 |

## 去重机制

- **地震**：按 `eventId + updates` 去重，同一地震的修正会再次推送
- **气象预警**：按 `warning.id` 去重，同一预警不会重复推送
- 状态持久化保存在插件目录的 `state.json`，重启不丢
